# /video/ — Folder chứa VIDEO

## Tên file chuẩn:
- featured-1.mp4   → Video nổi bật số 1 (hiển thị đầu tiên trong section Day)
- featured-2.mp4   → Video nổi bật số 2
- morning.mp4      → Video buổi sáng (07:30 – 10:30)
- noon.mp4         → Video buổi trưa (11:30 – 14:30)
- evening.mp4      → Video buổi chiều tối (17:30 – 22:00)
- night.mp4        → Video ban đêm (21:00 – 23:30)

## Định dạng khuyến nghị:
- MP4 (H.264), tối ưu cho web
- Độ phân giải: 1080p max
- Thêm poster image (thumbnail) cùng tên, đuôi .jpg
  Ví dụ: featured-1.mp4 → featured-1-poster.jpg
